Partida

Os botões usam o mesmo caminho da partida real (coach → daemon → OpenRGB). A sequência simula kill → double → morte 8 s → triple → quadra → penta, para conferir as interrupções.
A API do jogo expõe só o seu placar e eventos globais — sem posição no mapa, ouro do time ou wards. Os avisos usam só o que a API dá de verdade: timers contados a partir do evento real, níveis, itens e mortes.
